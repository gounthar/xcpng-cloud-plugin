A secret-text credential holding a Xen Orchestra authentication token. Only its ID is saved with the cloud; the token is looked up in the Jenkins credentials store each time a connection is opened.

The plugin only destroys the VMs it recorded creating, and tags each clone it sets up with an xcpng-cloud owner tag so tools/reaper.py can find it if it leaks. A clone whose create call fails while still in flight can be left untagged; the error names it, and it has to be removed by hand.

Neither the record nor the tag limits what the token allows: the token reaches every VM the Xen Orchestra user behind it can see, including VMs this plugin never created. Use a dedicated user, and avoid a token that can reach production VMs.
